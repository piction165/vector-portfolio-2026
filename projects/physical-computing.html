Physical Computing - 악수리 점프 게임

Arduino와 바닥 패드 입력을 Unity 게임과 연결해 몸으로 점프하며 플레이하는 인터랙티브 게임 프로젝트.

2025.03 - 2025.06 Unity Arduino Interactive

컨셉

연세 응원 마스코트 악수리를 특징으로 하는 점프 게임을 만들고, 플레이어의 실제 점프 입력으로 게임을 제어했습니다.

구현

바닥 패드 입력을 Arduino로 감지하고 Unity 게임 이벤트와 연결해 물리적 행동이 화면 속 액션으로 이어지도록 구성했습니다.

역할

  • 게임 컨셉 및 인터랙션 설계
  • 하드웨어 입력 흐름 구성
  • Unity 화면 및 플레이 구조 제작

확장

전시형 체험 콘텐츠나 캠퍼스 이벤트용 인터랙티브 게임으로 확장 가능한 구조를 만들었습니다.

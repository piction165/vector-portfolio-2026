# Vector World

Static personal portfolio for Vector.

## Structure

- `index.html` - landing page content
- `styles.css` - responsive Apple Developer-inspired visual system
- `assets/vector-world/` - compressed Vector avatar, photos, and YouTube thumbnails

## Deploy

Vercel serves this repository from the `main` branch.

- Framework preset: Other
- Build command: none
- Output directory: `.`

GitHub Pages can still serve the same static files if needed.
